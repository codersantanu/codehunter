# Canteen Companion Backend

## Overview

Canteen Companion is a Node.js backend application designed to facilitate the management of a college canteen. It provides functionalities for user authentication, menu management, order processing, and feedback collection.

## Features

- User authentication (login and registration)
- Menu management (view and add menu items)
- Order processing (create and fetch orders)
- Feedback submission and retrieval

## Technologies Used

- Node.js
- Express.js
- TypeScript
- MongoDB (or any other database of your choice)

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd canteen-companion-backend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   Create a `.env` file in the root directory and add your configuration settings (e.g., database connection string).

4. **Run the application:**
   ```bash
   npm start
   ```

5. **Run tests:**
   ```bash
   npm test
   ```
